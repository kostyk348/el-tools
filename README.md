# Electrical Tools (el-tools)

AutoLISP-инструменты для работы с электрическими схемами в AutoCAD:
трассировка цепей, дефектоскоп, симуляция разрывов, спецификации проводов.

## Установка

1. Скачайте папку `lsp/` целиком.
2. В AutoCAD: `APPLOAD` → выберите `electrical-tools.lsp` → «Загрузить».
   Загрузчик сам подтянет все остальные файлы.
3. Либо загружайте файлы по отдельности (`el-core.lsp` — обязательно первым).

> Требование: AutoCAD **2015+** (файлы в UTF-8 с BOM).
> На русской Windows работает в AutoCAD 2014 тоже.

## Команды

### Топология (ядро `el-core.lsp`)
| Команда | Назначение |
|---|---|
| `EL-TRACE` | Клик по LINE — трассировка всей цепи, подсветка, длина |
| `EL-WHATIF` | Симуляция разрыва: на какие части распадётся цепь |
| `EL-TABLE` | Таблица соединений «Откуда → Куда» по терминалам цепей |
| `EL-GRAPH` | Отладка: число линий/цепей, тексты цепей |

### Аудит и дефекты
| Команда | Назначение |
|---|---|
| `EL-CHECK` | Дефектоскоп: изолированные линии, near-miss разрывы, дубликаты текста, цепи без подписей |
| `EL-LOOPS` | Поиск колец/петель (цепь без терминалов) |
| `EL-BOTTLENECK` | Топ-10 линий, через которые проходит больше всего цепей |
| `EL-STATS` | Статистика: LINE/TEXT, цепи, распределение по размеру |
| `EL-HOTSPOTS` | Тепловая карта плотности линий |

### Версии и сравнение
| Команда | Назначение |
|---|---|
| `EL-SAVE-SNAPSHOT` | Снимок топологии (тексты цепей) в `.txt` |
| `EL-DIFF` | Сравнение текущей схемы со снимком: добавленные/удалённые/изменённые цепи |

### Спецификации и провода
| Команда | Назначение |
|---|---|
| `AW33` | Постраничная спецификация проводов: цвет/сечение/кол-во/длина + сводная таблица |
| `AW` | Тот же сбор, без таблиц (для программной обработки) |
| `DrawWire` | Рисование провода (полилиния + XData + номер в кружке) |
| `WireTable` | Таблица проводов из XData (`WIRE_DATA`) |
| `WireNodes` | Точки-узлы проводов на слое `WIRE_NODES` |
| `WireSegAddr` | Расстановка адресов точек разбивки вдоль линии |
| `WT` | Выноска «стрелка + номер» с двух концов |

### Перекрёстные ссылки
| Команда | Назначение |
|---|---|
| `EL-CROSSREF` | Поиск ссылок «лист N / sheet N / → N» в текстах, подсветка |

## Что оптимизировано (v2.x)

- **Скорость**: near-miss разрывы (`EL-CHECK`) и поиск текста — через
  пространственный grid-индекс вместо O(n²) полного перебора.
- **AW33 × количество**: длина умножается на кол-во проводов из строки
  (`N шт` или множитель `Nx…` в сечении); в таблицах появилась колонка «Кол-во».
- **Чистка**: убраны мёртвые функции (`el:load-snapshot`, заглушка
  `EL-CROSSREF-ALL` — полистовой анализ в C#-плагине), глобальные переменные
  локализованы (`el-whatif`).
- **Кодировка**: все файлы в UTF-8 (BOM).
- **Своя дедупликация точек** в `WireSegAddr` вместо сторонней `LM:UniqueFuzz`.

## Производительность

| Чертеж | Размер | EL-CHECK |
|---|---|---|
| малая схема | < 1k LINE | мгновенно |
| средняя | 1–5k LINE | < 1 сек |
| большая | 5–20k LINE | 1–5 сек |

(Граф строится один раз за команду; на повторных вызовах в рамках сессии
используется кэш `*el:line-ends*` / `*el:text-cache*`.)
